# GRADIENT BOUNDARY ANALYSIS (R2.3)

**Status: COMPLETE — and the answer is uncomfortable for the previous design.**

The brief's central scientific question:

> 在当前已有 signals 下，H1 与 mild gradient fault 是否真的可分？

Measured answer: **below ≈×2.5, no.** And the univariate feature Phase 1.3 relied on
is **worse than chance** in that region.

Generated by `tests/experiments/gradient_boundary.py`; raw data in
`outputs/phase1-4/gradient_boundary.json`. 6 seeds × (healthy heavy-tail, healthy
stable, and six fault magnitudes) = 48 real training runs.

---

## 1. Threshold-independent separability (AUC vs healthy heavy-tail)

Probability a random fault value exceeds a random healthy value. **0.5 carries no
information; below 0.5 means the feature points the wrong way.**

| Feature | ×1.5 | ×2.0 | ×2.5 | ×3.0 | ×4.0 | ×6.0 |
|---|---|---|---|---|---|---|
| `global_norm_ratio` — **what Phase 1.3 used** | **0.25** | **0.29** | 0.58 | 0.92 | 1.00 | 1.00 |
| `l2_aggregate` (joint) | 0.58 | 0.75 | **0.92** | **1.00** | 1.00 | 1.00 |
| `l1_aggregate` (joint) | 0.62 | 0.83 | **0.96** | **1.00** | 1.00 | 1.00 |
| `trimmed_l2` (joint, outlier-resistant) | 0.62 | 0.83 | 0.96 | 1.00 | 1.00 | 1.00 |
| `max_layer_ratio` | 0.50 | 0.75 | 0.88 | 0.92 | 1.00 | 1.00 |
| `fraction_above_2` | 0.58 | 0.67 | 0.75 | 0.75 | 1.00 | 1.00 |
| `fraction_above_1p5` | 0.42 | 0.54 | 0.54 | 0.92 | 0.92 | 0.92 |
| `top_k_mass` | 0.67 | 0.67 | 0.71 | 0.67 | 0.67 | 0.62 |
| `max_over_median` | 0.58 | 0.62 | 0.62 | 0.58 | 0.58 | 0.58 |

## 2. Finding 1 — the univariate feature is worse than chance at low magnitude

`global_norm_ratio` scores **AUC 0.25 at ×1.5 and 0.29 at ×2.0**. It is not merely
weak; it is *inverted*. A ×1.5 or ×2.0 fault produces a **lower** global-norm ratio
than a healthy heavy-tail run does.

The mechanism: the injected fault scales gradients including those of a run whose
baseline is already elevated, and the healthy heavy-tail class has a higher trailing
median, so the *ratio* is depressed. Phase 1.3's detector was therefore not
insensitive at the low end — it was **informative in the wrong direction**, which is
worse than random because a threshold cannot be tuned to fix an inverted signal.

This is the quantitative proof of the brief's R2 premise: **the gradient problem is
not univariate and never was.**

## 3. Finding 2 — joint aggregation separates, and where

`l1_aggregate` and `l2_aggregate` normalise each layer by its own trailing baseline
and then aggregate across layers. **AUC rises to 0.96 / 0.92 at ×2.5 and 1.00 at
×3.0**, against 0.58 / 0.58 for the univariate feature at the same magnitude.

`trimmed_l2` — discarding the single largest layer before aggregating — matches
`l1_aggregate` exactly (0.96 / 1.00), confirming the signal is genuinely distributed
across layers rather than carried by one outlier.

## 4. Finding 3 — not every sophisticated feature helps

`top_k_mass` (share of mass in the top third of layers) scores 0.62–0.71 at **every**
magnitude and never separates. `max_over_median` is similarly flat at 0.58. Both are
reported as negative results: a concentration statistic does not see this fault,
because the injection scales all layers roughly uniformly.

## 5. The overlap, and the boundary

`overlap = fault_min ≤ healthy_max`, i.e. the classes cannot be separated by that
feature alone:

| Feature | ×1.5 | ×2.0 | ×2.5 | ×3.0 | ×4.0 | ×6.0 |
|---|---|---|---|---|---|---|
| `l2_aggregate` | YES | YES | YES | **no** | no | no |
| `l1_aggregate` | YES | YES | YES | **no** | no | no |
| `trimmed_l2` | YES | YES | YES | **no** | no | no |
| `global_norm_ratio` | YES | YES | YES | YES | no | no |

Raw values for `l2_aggregate`:

```
healthy heavy-tail : median  8.18   max 12.84
healthy stable     : median  5.05   max 17.14      <-- higher max than heavy-tail
fault x3.0         : min 12.89   median 17.11
fault x4.0         : min 17.35   median 23.08
```

**Minimum reliably detectable magnitude ≈ ×3.0** using joint aggregation — improved
from ×4–6 with the univariate feature, but a real floor.

A caveat that matters: **healthy *stable* runs reach 17.14, higher than healthy
heavy-tail's 12.84.** The AUC above is computed against heavy-tail only, so
"heavy-tail is the hard class" is not established by this data. The boundary value
must be set against both healthy classes, and this analysis does not do that.

## 6. What the brief requires me to conclude

> 如果不可分：不能通过复杂规则假装可分。应该扩大 INSUFFICIENT_EVIDENCE 区域。

Below ≈×2.5 the classes are not separable on the signals already collected. The
correct system behaviour there is **`INSUFFICIENT_EVIDENCE`**, and the correct
product statement is:

```
minimum validated detectable gradient perturbation: not yet established
  -> the joint analysis supports separation at >= x3.0 on the development corpus
  -> anything below x2.5 is inside the abstention band
```

That is a capability boundary, not a failure, and it is the honest answer to R2.3.

## 7. Not done

* **The joint feature was not implemented in the detector.** R2.1–R2.4 specify the representation, the uncertainty band (`NORMAL` / `UNCERTAIN` / `CONFIRMED`) and frozen A/B boundaries. The measurement is complete; the implementation is not.
* **A/B boundaries were not frozen from development data.**
* **`R3` downstream corroboration was not attempted**, so `gradient + loss response` was not evaluated as a way to lower the boundary.
* **Separability is measured against heavy-tail healthy only**, not against healthy stable (§5).
* **6 seeds per class.** The AUC estimates carry wide intervals at this sample size; no confidence interval was computed.
